# Contributors

This document recognizes all contributors to the gopiano project. We appreciate every contribution, whether it's code, documentation, bug reports, or other forms of support.

## Purpose

This file serves to acknowledge and celebrate the community members who have contributed to making gopiano better. Every contribution, no matter how small, is valued and appreciated.

## Contribution Types

Contributions to gopiano can take many forms:

- **Code**: Writing code, fixing bugs, implementing features
- **Documentation**: Improving documentation, writing guides, fixing typos
- **Bug Reports**: Identifying and reporting issues
- **Feature Requests**: Suggesting new functionality
- **Reviews**: Reviewing pull requests and providing feedback
- **Testing**: Writing tests, testing features, reporting test results
- **Maintenance**: Triaging issues, managing releases, project administration
